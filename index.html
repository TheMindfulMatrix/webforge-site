  1. A domain pointing nowhere

    A club with hundreds of athletes had every page return an error instead of their site. Every parent who searched them and clicked got nothing. Nobody there knew.

  2. Pages too heavy for a phone

    One site weighed 2.4 MB. A parent checking practice times on mobile data gives up before it finishes loading.

  3. Seasons that ended two years ago

    Stale schedules, dead footers. The site quietly tells a new family that the program might not exist anymore.

  4. Two live domains, same content

    Split traffic, split search results, and parents landing on whichever one Google felt like showing that day.

None of these are design problems. They're maintenance problems. A broken domain isn't a site that was built badly — it's a site nobody was responsible for.
